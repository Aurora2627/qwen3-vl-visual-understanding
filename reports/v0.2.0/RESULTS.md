## 失败案例

- decomposed / count-negative：参考 FAIL，输出 INVALID；解析错误 Condition count mismatch。
- decomposed / position-negative：参考 FAIL，输出 PASS；解析错误 None。

## 输入控制

- mismatched_image：{"PASS": 0, "FAIL": 8, "UNCERTAIN": 0, "INVALID": 0}；与原图整体判断相同 4/8。不计算正确率，因为原图标签不适用于更换或移除图像后的输入。
- no_image：{"PASS": 8, "FAIL": 0, "UNCERTAIN": 0, "INVALID": 0}；与原图整体判断相同 4/8。不计算正确率，因为原图标签不适用于更换或移除图像后的输入。

无图时仍全部回答 PASS，说明本协议未能可靠让模型识别缺少视觉证据。真实使用必须在入口校验图片；不能把该模型直接当作可靠的自动裁判。错配图全部 FAIL 仅是输入敏感性观察，不能证明可靠 grounding。

## 结论与下一步

本次逐条件协议未优于整体判断：少返回一个数量条件，且把左右关系判断反。八例结果不能推广至真实生成图。保留失败输出，不调整标签；下一步扩充真实文生图与独立人工标注，按指令分组隔离开发/测试数据，再研究协议和校准。
